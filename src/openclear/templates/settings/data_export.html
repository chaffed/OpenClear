Generates a downloadable archive containing every record and file belonging to your organization — accounts, issued items, stop payments, paid items, ACH records, exceptions and decisions, check images, users, SSO configuration, customers, bulk upload files, and the action log. Passwords and SSO client secrets are never included. Building the archive runs in the background — refresh this page to see when it's ready to download.

This action is intentionally not granted to every admin by default — it's a meaningful way for all of an organization's data to leave the system, so it has its own permission (data_export:run) that must be explicitly added to a security group from the Security Groups page.
