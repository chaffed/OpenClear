Decisions

A different person must make the final pay or return decision than the one who recommended it. Takes effect at once for every exception.

A second admin for settings changes

Matching rules, scoring models, security groups, single sign-on, API clients, webhooks and the like wait for someone else who could make the change.

Adding someone, or giving someone more access, waits for another person who manages users. Removing or narrowing access never waits.

Turning a protection off (any of these, segregation of duties, lockout, password and inactivity rules, required sign-on, security event forwarding) always needs a second admin. Each switch turns on only while someone else can approve.
