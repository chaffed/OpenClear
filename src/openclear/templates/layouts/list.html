A layout tells OpenClear how to read an issued-check file that isn't in OpenClear's own column format: which column (or which characters, in a fixed-width file) holds the account, check number, amount, date and payee, and how amounts and dates are written.

Build one from a sample of your file. Each upload records the layout it used, so changing a layout later doesn't change what an earlier upload meant.

The default layout is chosen for you when you upload. A customer's own default comes before the bank's.
