Each network can score this customer's exceptions with either the bank's model or a model trained only on this customer's own decision history. The bank's model is whichever the bank chose in Settings: the shared network model or the bank's own model.

  • Auto (the default) uses this customer's own model as soon as one has been trained and activated, and the bank's model until then. No action is needed.
  • Bank's model always uses the bank's model, even if this customer has its own.
  • This customer's model prefers this customer's own model, and uses the bank's model only while it has none.

"Scoring with now" shows which model is actually in use. Retraining and activating below apply only to this customer's own model.

Default disposition decides what happens to an exception if no one responds within its response window: "None" (default) leaves it open indefinitely; "Always pay"/ "Always return" apply a fixed outcome; "ML-determined" re-scores the exception at the deadline and picks pay/return from the model's own probability. An ACH return (fixed or ML-determined) needs a return reason from this tenant's own catalog — if none is configured, that customer+ACH auto-decisioning is skipped rather than guessed, and retried on the next sweep.
