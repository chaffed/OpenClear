{% extends "base.html" %} {% import "_macros/responsive_table.html" as rt %} {% from "_macros/icon.html" import icon %} {% block title %}API clients — {{ ctx.tenant_name }}{% endblock %} {% block help_title %}About API clients{% endblock %} {% block help_body %}

An API client lets one of your systems (your core, your online banking provider, your own middleware) call OpenClear's API without a person's password. It signs in with OAuth 2.0 client credentials: its client id and secret, exchanged at POST /api/v1/oauth/token for an access token that lasts a short while.

Each client can do exactly what its security group allows, and only for its customer if you pick one. Everything it does is in the audit log under its name. Rotate a secret if it may have leaked; revoke a client you no longer use (that takes effect at once).
