Each fee charges for one thing OpenClear counts, such as checks presented, exceptions, returns, accounts or users. Give each fee your own AFP code (and bank service code, if you use one): banks code positive pay differently, so none is assumed. The codes appear on the analysis feed and the camt.086 statement.

Prices can have up to four decimal places. A fee can use volume tiers (each tier's units at that tier's price) and a monthly minimum. Negotiated prices and waivers for individual customers are set on each customer's billing terms.
