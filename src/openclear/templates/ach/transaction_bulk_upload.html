NACHA file

Upload a standard 94-character fixed-width NACHA file. Originator company ID/name, SEC code, and effective date come from each batch header (record type 5); amount, receiver ID, DFI account number, and trace number come from each entry detail record (record type 6). File/batch control totals (record types 8 and 9) are not validated — a malformed file may partially import rather than being rejected outright.
