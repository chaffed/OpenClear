Data Export

Data export bundles all of a tenant's or a single customer's data into a downloadable file — useful for migrating to another system, or for offboarding a customer. This is a deliberately opt-in permission, not automatically granted even to Admin, since a full export is a single action capable of moving everything a tenant or customer has to an outside party.

How to

  • Export an entire tenant — from Settings → Data Export, start a job and download it once it completes.
  • Export a single customer — from that customer's detail page, use its own data export option to scope the export to just that customer's records.

Export jobs run in the background. Because an archive is a full copy of your data, it's kept for a limited time (30 days unless your platform operator has set otherwise) and then deleted; the export shows as expired, and you can start a new one.
