Audit Log

The audit log is an immutable, tenant-wide record of every write action taken in OpenClear, across both the web UI and the API — who did what, and when.

{{ docs.screenshot("audit_log", "Audit log screen") }}

How to

  • Browse — open Audit Log to see entries in order, most recent first.
  • Verify integrity — the "Verify" action checks the log's hash chain end to end, confirming no entry has been altered or removed since it was written.
  • Archived entries — your platform operator can have older entries moved out of the live log into signed archive files, so it stays fast as it grows. Nothing is lost: each archive is listed under "Archived entries" with a download link (one entry per line, with everything needed to check its signature), "Verify" checks the archives too, and the live log carries on from the last archived entry.

This is a bank-wide view (not available in a customer-scoped session) and, like other management-oriented permissions, isn't automatically included in every default security group — only Admin has it out of the box.
