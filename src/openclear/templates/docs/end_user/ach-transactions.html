ACH Transactions

ACH transactions are incoming debits and credits presented against an account over the ACH network. Each one is automatically screened against that account's ACH authorizations (allow rules) — anything not matched by an existing rule becomes an exception for review, the ACH equivalent of a positive-pay mismatch.

{{ docs.screenshot("ach_transactions", "ACH transactions list") }}

How to

  • Enter a single transaction — open ACH Transactions and choose "New."
  • Submit a batch — use bulk upload for a full batch of incoming ACH activity; see Bulk File Uploads.

To pre-approve activity from a known originator so it stops triggering exceptions, see ACH Authorizations & Allow Rules.
