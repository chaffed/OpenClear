Issued items

An issued item is a check your company has written. Recording it in OpenClear lets the bank match it against checks that are later presented for payment — anything presented that doesn't match a recorded issued item (wrong amount, wrong payee, or simply unknown) becomes an exception for review.

{{ docs.screenshot("issued_items", "Issued items list") }}

How to

  • Record a single check — open Issued Items and choose "New." Enter the account, check number, amount, payee, and issue date.
  • Record many checks at once — use the bulk upload option from the same screen to submit a file covering a batch of checks (e.g. an accounts-payable run). See Bulk File Uploads for the general upload/undo workflow.
  • Void an issued item — if a check was recorded in error or will never be presented (e.g. it was destroyed before mailing), void it from its detail page so it no longer counts as outstanding.

Your dashboard's "outstanding issued items" count reflects issued items that haven't yet been matched to a paid item, voided, or stopped.
