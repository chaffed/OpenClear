ACH Authorizations & Allow Rules

An ACH authorization is an allow rule for a specific account: it tells OpenClear which originators are pre-approved to debit or credit that account, so matching transactions don't generate an exception. Rules can be scoped by originator ID, originator name, receiver ID, and SEC code.

How to

  • Create a rule from scratch — open ACH Authorizations and choose "New," then fill in the account and originator details.
  • Create a rule directly from an exception — when you're reviewing an ACH exception that turns out to be legitimate, use the "Add allow rule" action on the exception. It opens the new-authorization form already filled in with that transaction's account, originator ID, originator name, receiver ID, SEC code, and today's date as the effective date — so approving a one-off false positive and pre-approving future activity from the same originator is a single click plus a save, instead of retyping everything.
  • Revoke a rule — once an originator should no longer be pre-approved, revoke its rule from the authorizations list.

See Exceptions & Decisioning for how allow rules interact with the exception queue.
