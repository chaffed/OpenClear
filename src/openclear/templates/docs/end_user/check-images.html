Check Images

Check images are the front and back scans of a physical check, attached to a paid item so reviewers can visually verify signatures, endorsements, and alterations during exception review.

{{ docs.screenshot("check_images_bulk", "Check image bulk upload") }}

How to

  • Upload a single image pair — open Check Images and choose "Upload," providing the front and back image files for a check.
  • Upload in bulk — submit a batch of image files at once (typically alongside a matching paid-items file for the same day's activity). See Bulk File Uploads for the general workflow.
  • Reprocess — if an image failed to link to its paid item correctly, trigger reprocessing from the image's detail page to re-run matching.
  • View — front and back images are viewable (and downloadable) individually from each check's detail page.
