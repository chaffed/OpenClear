Bulk File Uploads

Most record types in OpenClear support bulk upload, so you can submit a whole day's or batch's worth of activity as a single file instead of one entry at a time: issued items, paid items, ACH transactions, check images, accounts and users.

How it works

  • Each upload creates a record you can return to later — its detail page shows how many rows succeeded, how many failed and why, and lets you re-download the original file.
  • Undo an upload — every bulk upload can be "backed out." This reverses exactly the records that upload created, after re-checking that nothing about them has changed since (for example, an item that's already been paid or decided can't simply be un-created out from under that activity).

Fixing rows that failed

When some rows fail, the upload's page lists them with the reason, naming the field at fault ("Amount: '1,2O0.00' contains a letter"). Press Fix failed rows to edit them in place: each row shows its values with the problem beside the field, and Import fixed rows imports only the rows you ticked. The file you uploaded stays exactly as it was received; each fix is recorded separately, with who made it, and backing the upload out reverses what the fixes created too.

Your own file format: layouts

An issued-check file that isn't in OpenClear's own columns (a different header, no header, a fixed-width file, or a spreadsheet) can be read with a layout. Build one under Settings → Issue-file layouts:

  1. Choose a sample of your file and press Show sample.
  2. For a delimited or Excel file, choose what each column holds from the list above it. For a fixed-width file, select a field's characters in the sample and press Use selected text, or type its start and length.
  3. Say how amounts (with a decimal point, or implied cents) and dates (such as MMDDYY) are written, and whether a column marks voids. Press Preview to see what would be imported, then Save.

Choose the layout when you upload; your default is chosen for you. Files dropped in your bank's drop folder use your default layout too. A file that fails because its columns don't match offers to start a layout from that very file. A void line in an issue file voids the check already issued with that number, or records it as voided if it isn't on file yet.

Start a bulk upload from the relevant feature's own page (for example, Issued Items or ACH Transactions) — there's a "Bulk upload" option alongside "New" on each.
