Known-Fraud Training Data

The fraud model gets better when it sees labeled examples of confirmed fraud. This feature lets you feed a known-fraud check or ACH item into the training pipeline, either by pointing at an item you've already entered or by describing a new one directly. This is an opt-in permission — most users won't see it.

How to

  • Open Fraud Training Data.
  • Label an existing item — search for a paid item or ACH transaction you already recorded and mark it as known fraud.
  • Enter a new example — use the check or ACH single-entry form to describe an item that wasn't otherwise recorded in OpenClear, purely for training purposes.
  • Submit in bulk — upload a file of multiple known-fraud examples at once, for either network.
  • Retract a mislabeled example — if an item was labeled in error, retract it from the same screen so it stops influencing training.

Training examples are tracked separately from live exceptions, so they never inflate your organization's real exception counts or reporting.
