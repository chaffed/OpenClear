Every state-changing action, through either the web UI or the API, is recorded here — one entry per row created even for a bulk upload, not one entry for the whole file. Entries form a tamper-evident hash chain: each one's hash covers its own fields plus the previous entry's hash, so editing, deleting, or reordering any entry breaks the chain from that point forward.

"Verify chain" recomputes every hash from scratch right now — proof nothing has been tampered with since, not a cached flag.

If your platform archives older entries, they're moved into signed files listed under "Archived entries", which you can download. Verifying checks those files too, and that the entries here carry on from the last one archived.
