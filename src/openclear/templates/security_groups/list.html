A security group is a named, editable set of permissions — not a fixed role. Every new organization starts with four (Admin, Preparer, Approver, Viewer), fully editable from here. A user's membership pairs one security group with a scope (bank-wide or one customer) — the group defines what they can do, the membership's scope defines whose data it applies to.

Editing a group's permissions takes effect for everyone in it on their very next request — not after their session expires.
