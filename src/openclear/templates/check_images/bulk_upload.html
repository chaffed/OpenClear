ZIP file (manifest + images)

A zip containing exactly one manifest file (CSV, TSV, or Excel) plus the image files it references. Supported image formats: single- or 2-page TIFF (page 1 = front, page 2 = back), JPG, and PNG. Manifest columns (case/spacing-insensitive, any order):

X9.37 cash letter file

Upload a standard image cash letter file (the common ASCII, line-delimited "variable format" variant, with embedded TIFF or JPEG images). Account number and check number are read from each check's On-Us and Auxiliary On-Us MICR fields — a common real-world convention, not a guarantee for every bank's own MICR layout; if a file's checks don't resolve correctly this way, use the ZIP+CSV format above instead, which lets you specify account and check numbers explicitly. The file's bundle, cash-letter and file control totals (item count and dollar amount) are checked: if any of them doesn't match the checks in the file, nothing is imported.
