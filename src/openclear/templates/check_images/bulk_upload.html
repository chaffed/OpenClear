ZIP file (manifest + images)

A zip containing exactly one manifest file (CSV, TSV, or Excel) plus the image files it references. Supported image formats: single- or 2-page TIFF (page 1 = front, page 2 = back), JPG, and PNG. Manifest columns (case/spacing-insensitive, any order):

X9.37 cash letter file

Upload a standard X9.37 image cash letter, as your processor sends it (EBCDIC or ASCII, with TIFF or JPEG images). The account number is read from each check's On-Us MICR field and the check number from its Auxiliary On-Us field (or from On-Us after the on-us symbol, for personal checks). That's the usual layout, but not every bank's; if a file's checks don't resolve this way, use the ZIP+CSV format above, which lets you give account and check numbers explicitly. The file's bundle, cash-letter and file control totals (item count and dollar amount) are checked: if any doesn't match the checks in the file, nothing is imported. Return cash letters aren't accepted.
